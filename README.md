# IBRA DRIVE CHECK

**نظام احترافي لفحص وحدات التخزين وكشف السعات المزيفة — ويندوز 10 / 11 (64-bit)**

برنامج مجاني بالكامل، يعمل بدون إنترنت، بدون حساب أو اشتراك أو مفتاح تفعيل.
برمجة وتطوير **ابراهيم الخزرجي** — [ibraprogram.netlify.app](https://ibraprogram.netlify.app/) · [Telegram](https://t.me/ibraprogram) · TikTok: ibraprogram

## ماذا يفعل؟

| الميزة | الوصف |
|---|---|
| **الفحص الشامل للشراء ("هل أشتريه؟")** | ضغطة واحدة: الصحة ← كشف السعة الوهمية ← السرعة ← حكم نهائي: *زين اخذه / مقبول بملاحظات / لا تاخذه*، مع التوافق مع الحاسبة (اختياري) |
| **الفحص السريع** | 576–1152 منطقة على شبكة منتظمة تغطي كامل السعة المعلنة، كتابة مؤقتة مع نسخ احتياطي وإعادة البيانات الأصلية |
| **الفحص العميق** | 4096–8192 منطقة لتقدير أدق للسعة الحقيقية |
| **فحص السعة الكامل (المساحة الفارغة)** | يملأ المساحة الفارغة بملفات اختبار فريدة، يتحقق منها، ثم يحذفها — بدون صلاحيات مسؤول |
| **فحص السعة الكامل (مدمر)** | يكتب ويقرأ كل بايت في الوحدة بعد موافقة مكتوبة صريحة |
| **فحص القراءة فقط** | لا يكتب أي شيء: أخطاء القراءة والمناطق البطيئة |
| **اختبار السرعة** | قراءة/كتابة متسلسلة، عشوائية 4K، IOPS، زمن الاستجابة (متوسط/أقل/أعلى) — أو قراءة مباشرة فقط للوحدة غير المهيأة |
| **صحة الوحدة** | SMART عبر ويندوز + سجل NVMe الصحي (البيانات المكتوبة، ساعات التشغيل، الاستهلاك، أخطاء الوسيط، الحرارة) |
| **إصلاح السعة وتغيير حجم القسم** | قسم واحد بالحجم الحقيقي للوحدة المزيفة (MBR — لأن نسخة GPT في آخر القرص تقع في المنطقة الوهمية)، أو أي حجم تختاره |
| **استعادة المحذوفات** | NTFS (سجلات MFT) و exFAT و FAT32/16 مع شجرة المجلدات — ملف واحد أو مجلد كامل أو الكل — وبحث عميق يستخرج JPG/PNG/GIF/PDF/DOCX/XLSX/PPTX/ZIP/APK/MP4/MOV/WAV/AVI من المساحة الفارغة |
| **إزالة الآثار** | محو أسماء المحذوفات (ملء سجلات MFT / تصفير مدخلات FAT و exFAT)، مسح المساحة الفارغة، حذف سجل USN، حذف آمن لملفات ومجلدات |
| **خريطة مباشرة** | أخضر سليم · أحمر فاشل/التفاف · برتقالي خطأ كتابة · بنفسجي خطأ قراءة · أصفر بطيء · أزرق جاري · رمادي لم يُفحص — اضغط أي مربع لتفاصيله |
| **السجل والتقارير** | حفظ محلي، مقارنة فحصين، تصدير PDF / CSV / JSON / HTML، طباعة |
| **الإشعارات** | توصيل وحدة، انتهاء الفحص، سعة مزيفة، أخطاء، حرارة، انقطاع — كل نوع يُفعل منفصلاً |
| **عربي / إنجليزي** | RTL و LTR بالكامل، وضع فاتح وداكن |

## كيف يكشف السعة المزيفة؟

1. يقرأ المحتوى الأصلي لكل منطقة ويحفظه في **سجل استعادة على قرص النظام** قبل أي كتابة.
2. يكتب في كل منطقة كتلة 4KB فريدة: معرّف جلسة عشوائي + رقم الكتلة + العنوان + SHA-256 للبيانات.
3. الكتابة **من أعلى السعة إلى أسفلها**، والعينات على **شبكة بخطوة قوة للعدد 2** — الذاكرة المزيفة تلتف عادةً بحجم قوة للعدد 2، فكل عينة فوق الحجم الحقيقي تقع بالضبط على عينة أدنى منها، ويُكتشف الالتفاف بشكل مؤكد وليس بالصدفة، ويُحسب الحجم الحقيقي من مسافة الالتفاف.
4. بعد انتهاء كل الكتابات يقرأ الجميع ويتحقق: مطابق ✓ / بيانات منطقة أخرى (التفاف) / أصفار أو FF (منطقة وهمية) / Hash غير مطابق (تلف) / خطأ قراءة أو كتابة.
5. يعيد البيانات الأصلية ويتحقق منها بايت بايت، ثم يحذف سجل الاستعادة.
6. لا يصدر حكم "مزيف" من عينة واحدة: يحتاج نمط "سليم ثم تالف حتى النهاية" بمنطقتين على الأقل، أو دليل التفاف صريح. ويميز بين **السعة المقدرة** و**السعة المتحقق منها بالكامل**.

## الحماية

- الكتابة المباشرة مسموحة فقط على وحدات USB/SD الخارجية، أو قرص داخلي **جديد غير مهيأ** (بدون أقسام).
- ممنوع على قرص النظام، وعلى أي قرص فيه أقسام ويندوز أو استعادة (MSR / Recovery).
- التحقق من هوية القرص (الموديل + الرقم التسلسلي + الحجم) قبل أي كتابة، وقفل وفصل الأقسام أثناء الفحص.
- موافقة صريحة قبل أي كتابة، وكتابة حجم الوحدة للتأكيد قبل الفحص المدمر. لا تهيئة ولا إصلاح تلقائي.
- إلغاء آمن في أي لحظة (تُعاد البيانات الأصلية)، وإغلاق البرنامج أثناء الفحص ينتظر الإعادة.
- إذا أزيلت الوحدة أثناء الفحص: يبقى سجل الاستعادة، وعند إعادة توصيلها يظهر زر **استعادة البيانات الأصلية**.
- **لا يوجد ضمان مطلق**: الوحدة المزيفة قد تتلف الملفات حتى بدون أي فحص. خذ نسخة احتياطية دائماً.

  Storage/ Reports/ Localization/

tests/IbraDriveCheck.Tests محاكاة وحدات مزيفة + اختبارات ويندوز حقيقية على قرص افتراضي
