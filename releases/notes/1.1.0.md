## IBRA DRIVE CHECK 1.1.0

- **إصلاح السعة وتغيير حجم القسم:** للفلاشة أو الهارد المزيف، ينشئ قسماً واحداً بالحجم الحقيقي فقط (بنمط MBR) حتى لا تتلف الملفات. يمكنك أيضاً اختيار الحجم الكامل أو أي حجم مخصص، مع خيار فحص القسم الجديد بالكامل بعد الإصلاح.
- **استعادة الملفات المحذوفة:** يدعم NTFS و exFAT و FAT32/16. يعرض المحذوفات بشجرة مجلداتها، فتختار ملفاً واحداً أو مجلداً كاملاً بكل ما فيه أو الكل. البحث العميق يستخرج الصور والفيديو والمستندات حتى بعد التهيئة.
- **إزالة آثار المحذوفات:** محو أسماء الملفات المحذوفة، مسح المساحة الفارغة، حذف سجل تغييرات NTFS، والحذف الآمن لملفات ومجلدات.
- زر "إصلاح السعة" يظهر مباشرة في نتيجة الفحص عند اكتشاف سعة مزيفة.
