## IBRA DRIVE CHECK 1.2.0

**ترتيب جديد وبسيط:** البرنامج صار 7 أقسام واضحة (الرئيسية، الفحص، الصحة، الإصلاح والاستعادة، الحماية والأمان، السجل والتقارير، الإعدادات)، وكل قسم فيه تبويبات، مع مهام سريعة بالرئيسية.

**الجديد:**
- **الحماية من الفيروسات:** كشف فيروس الاختصارات و autorun.inf والسكربتات المخفية، عزلها بأمان، وإرجاع الملفات المخفية، وتحصين الفلاشة.
- **قفل الكتابة:** قفل فلاشة معينة (قراءة فقط)، أو منع الكتابة على كل فلاشات USB بالحاسبة.
- **المسح الكامل قبل البيع:** كتابة فوق كل الوحدة (مرة أو 3 مرات) مع التحقق، وأمر المسح الداخلي لأقراص NVMe عند توفره.
- **المراقبة بالخلفية:** أيقونة بجانب الساعة تراقب الحرارة والصحة وتنبهك، مع خيار التشغيل مع ويندوز.
- **عمر الـ SSD:** تقدير العمر المتبقي بالسنوات حسب الاستهلاك والتحمل المعلن (TBW).
- **اختبار التحمل الطويل:** كتابة وقراءة لساعات يكشف الأقراص التي تعطل بعد أيام.
- **مقارنة الموديل:** سرعتك الفعلية مقابل سرعة الشركة لنفس الموديل مع تفسير الفرق.
- **نسخ القرص:** صورة كاملة VHD أو IMG (تتخطى القطاعات التالفة) وإرجاعها.
- **فحص الملفات التالفة:** صور وفيديو ومستندات وملفات مضغوطة، ويكشف الملفات التي صارت أصفاراً.
- **فلاشة لا تفتح / تطلب تهيئة:** يبحث عن نظام الملفات المفقود ويستعيد ملفاتك قبل التهيئة، ويصلح قطاع الإقلاع من النسخة الاحتياطية.
- **الإخراج الآمن الذكي:** يكشف أي برنامج أو نافذة تمسك الفلاشة.
